# Королевства Пепла 9.2.0 — Living World Engine

Мобильная браузерная стратегия на базе 9.1.2. Карта мира, подземелье и бой используют собственные Canvas 2D сцены с изометрической проекцией. Все ресурсы поставляются локально, CDN и установка зависимостей для игры не нужны.

## Запуск

Для GitHub Pages распакуйте содержимое ZIP в корень публикуемой папки: `index.html`, JavaScript, CSS и папка `assets` должны находиться рядом. Опубликуйте папку обычным способом GitHub Pages. Сайт должен открываться через HTTP/HTTPS; для PWA требуется HTTPS или localhost.

Локально из папки проекта:

```sh
python3 -m http.server 8000
```

Откройте `http://localhost:8000`. При открытии `index.html` как локального файла PWA и обновления service worker недоступны.

## Управление

- Перетаскивание карты — обзор; pinch или кнопки +/− — масштаб.
- Нажатие на свободную клетку — движение. Первое нажатие на объект выделяет его, повторное предлагает взаимодействие или подход. Доступен список разведанных объектов.
- В подземелье нажатие задаёт пошаговый маршрут; герой плавно проходит его с расходом движения.
- В бою нажмите на доступную клетку или фигуру противника. Альтернативные команды доступны в «Списке клеток и целей».
- Музыка запускается после разрешённого взаимодействия. Громкость, музыка и звуковые эффекты настраиваются отдельно.

## Совместимость и обновление

Схема сохранений остаётся `1`. Сохранения 9.1.x мигрируются без сброса кампании. Повреждённое сохранение показывает ошибку и средства восстановления. Удалять данные браузера для обновления не требуется.

Service worker 9.2.0 использует отдельный кэш для адреса установки. `index.html` запрашивается из сети с `no-store`, при отсутствии сети используется сохранённая копия. Старые кэши этого же приложения удаляются; чужие приложения не затрагиваются.

```sh
npm test
```

## Для разработки

Модель и правила: `game-core.js`; каталог и проходимость: `game-data.js`; движение/жесты: `game-controls.js`; камера: `scene-camera.js`; сцены мира: `scene-renderer.js`; бой: `scene-battle.js`; музыка: `music-engine.js`; DOM-интерфейс: `game-ui.js`; один CSS: `game.css`.

`?debug-nav=1` включает диагностическую сетку. По умолчанию она выключена.

`qa/visual.html?qa=1&scene=map` запускает воспроизводимую визуальную сцену с сохранениями только в памяти. Сценарии: `map`, `castle`, `movement`, `selected`, `threat`, `dungeon`, `dungeon-fog`, `battle-surface`, `battle-abyss`, `city`, `hero`. Страница QA не читает и не заменяет сохранение игрока, не регистрирует service worker и не сохраняет масштаб. В `movement` время анимации специально сдвинуто и замедлено для снимка промежуточного положения.
