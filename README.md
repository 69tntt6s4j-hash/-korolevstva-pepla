# Королевства Пепла 8.8.2

## 8.8.2 — Living World Update

На глобальной карте добавлены лёгкие фоновые анимации воды: течение рек и озёр, прибой вдоль берегов и пена/движение на ключевых водопадах. Эффекты рисуются поверх `world-v6.jpg`, но под туманом войны, не меняют проходимость и игровое состояние. Обновление ограничено примерно 10 FPS и отключается при `prefers-reduced-motion`.

Дополнение 8.7.2: реальные боевые стеки больше не становятся полупрозрачными из-за disabled-состояния клеток тактической сетки; спрайты слегка усилены по контрасту и насыщенности.

Исправленная отдельная копия версии 8.6.5. Изображение мира, оформление и базовые характеристики войск сохранены. Старые файлы игры не требуются для запуска новой версии.

## Запуск

1. Полностью распакуйте ZIP в отдельную папку.
2. Откройте `index.html` в современном браузере. Не открывайте HTML внутри просмотрщика архива.
3. Для установки приложения и офлайн-кэша разместите всю папку на HTTPS-сайте или используйте локальный HTTP-сервер на localhost. Серверная часть и сборка не нужны.

При запуске через `file://` доступность сохранений зависит от браузера. Если хранилище запрещено, игра показывает ошибку и не подменяет существующую кампанию пустой. Для предсказуемой работы сохранений используйте постоянный HTTP/HTTPS-адрес. Встроенный просмотрщик файлов телефона может не исполнять JavaScript.

## Сохранения

Автосохранение происходит после игровых команд. В настройках доступны ручное сохранение, экспорт JSON и импорт. Переносите экспортированный JSON вместе с игрой при смене браузера, устройства или адреса сайта.

Ключ новой версии: `ash-kingdom-full-fix`; резервный снимок: `ash-kingdom-full-fix:backup`. При повреждении основного снимка загрузчик проверяет резервный. До первого сохранения новой линии кампании он также проверяет поддерживаемые ключи старых версий, если браузер предоставляет их на том же origin. Скопированная папка не обязательно получает доступ к localStorage другой папки.

«Новая игра» и импорт требуют подтверждения внутри игры и архивируют доступные прежние данные. Старые версионные ключи не удаляются. После явного сброса повреждение нового сохранения не возвращает автоматически старую кампанию. Сохранения, которые уже были повреждены или перезаписаны в 8.6.5, нельзя достоверно восстановить без отдельной копии.

## Управление

Нажмите объект для выбора, повторно — для подхода или открытия карточки армии. Взаимодействие разрешено из своей или соседней по стороне клетки после разведки. Кнопка «Объекты рядом» открывает список всех разведанных объектов, отсортированный по расстоянию. Перетаскивание двигает камеру; два пальца меняют масштаб. Стрелки при фокусе на карте перемещают обзор; Enter открывает список целей.

Смена героя и следующий день отменяют маршрут. Зелёный отрезок доступен сегодня, серый выходит за запас движения. При повышении уровня сначала завершите выбор навыка. Дистанционный найм пополняет гарнизон; забрать его можно у города. «Пропустить ход» завершает ход текущего стека. Цель заклинания показана до применения.

## Проверки и ограничения

Для тестов нужен Node.js 18 или новее. Внешних библиотек и `npm install` не требуется:

```sh
node tests/regression.cjs
```

Или `npm test`. Результат записывается в `qa/regression-results.json`. В поставке: 99 успешных автоматических проверок. Это проверки правил, таймеров, DOM-адаптера и изолированного service worker; они не являются прохождением в реальном браузере. Safari/iOS, Android, FPS, экранный диктор и установка PWA на устройстве ещё требуют ручной проверки.
