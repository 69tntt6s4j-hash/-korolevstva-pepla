# 9.2.0 — Living World Engine

База: 9.1.2. Боевые характеристики, навыки, цены, улучшения, составы армий и 50 объектов основной карты сохранены.

- Вместо старого изображения с маркерами: слоистая Canvas-сцена с изометрической проекцией, камерой, отдельными объектами/актёрами, мягким fog и локальными эффектами.
- Общая камера поверхности и пещеры: pan, pinch, zoom, центрирование, плавное следование, сохранение масштаба, корректный resize.
- Прозрачные атласы окружения и персонажей; порядок по глубине, тени, перекрытие героя декором, слабый параллакс высоких элементов.
- Движущаяся вода, блики/пена, водопады, лава, факелы, дым и магические частицы. Захват получает локальный эффект.
- Отдельные UNKNOWN / EXPLORED / VISIBLE состояния fog.
- Подземное движение подтверждается по одной клетке; мосты соединены; скрытые объекты не активируются дистанционно.
- Полноценные Canvas-фигуры в бою: движение, рывок, налёт, снаряды, заклинания, лечение, реакция на урон и смерть. Расчёт боя остаётся в Engine.
- Исправлено попадание по всей площади боевой клетки и по верхней части фигуры; повторный ввод блокируется во время визуального действия.
- Уничтожение подвижных сил Некрополя обнуляет угрозу, снимает осаду и закрывает соответствующую задачу.
- Исправлены сохранение/восстановление подземного боя, проверка повреждённого подземного состояния и выход во время боя.
- Здания перестали быть транзитными клетками. У рудника добавлен обход; вражеская армия захватывает ресурс с соседней клетки.
- Шесть многоголосных музыкальных тем, плавные переходы, регулировка громкости, остановка при скрытии страницы.
- Единый мобильный CSS и Canvas-управление, доступные альтернативы боевым кликам, контролируемая загрузка ресурсов.
- Старые карты, маски и рендереры удалены из поставки; обновлены PWA/cache/manifest.
- 180 автоматических проверок и 33 мобильных скриншота, плюс проверка zoom/drag и музыкальных переключателей.

Ограничения: используются спрайты и процедурная анимация, детализация ниже художественных референсов; физический iPhone/Safari не был доступен для прогона. Подробности в техническом отчёте.
