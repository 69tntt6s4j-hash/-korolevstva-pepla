# Технический аудит базы 9.1.2

Единственная база — `korolevstva_pepla_9_1_2.zip`. До изменений создана побайтовая резервная копия. SHA-256 оригинала и копии:

`fad3c24675d830a6aeac434f75be4407a2abe8856c2ca0cad0f82b14f417c5dc`

Размер исходного ZIP: 8 107 318 байт. Исходник в Downloads не изменён. Результаты исходных тестов: 123/123 регрессии, 9/9 тестов 9.x. Зелёный baseline не доказывал отсутствие перечисленных ниже дефектов: несколько проверок UI проверяли наличие строк старого CSS, а сохранение подземного боя не входило в набор.

## Архитектура до изменений

| Область | Фактическая реализация 9.1.2 | Ограничение или дефект |
|---|---|---|
| State | Сериализуемая модель, schemaVersion 1, герои, объекты по ID, армия Морвейна, q/story, dungeon, battle, очередь навыков | Саму структуру можно сохранить; не требуется переписывать боевые правила |
| Координаты | Поверхность 26×20, клетка 100 условных единиц; подземелье 13×10 | Рисование зависело от изображения и отдельных визуальных поправок |
| Pathfinding | BFS по четырём соседям, блокировка воды/гор и охраны, подход на соседнюю клетку | Активные здания оставались транзитными клетками |
| Карта | Canvas с world-v7.jpg, маркерами и подписями | Глубина и ландшафт зависели от запечённого изображения |
| Объекты | Каталог стабильных ID, поверх карты рисовались кружки/изображения/подписи | Объект воспринимался как маркер; не было полноценного порядка перекрытия |
| Pointer | Общий контроллер для основной карты, отдельная реализация пещеры | Поведение pinch/cancel на картах расходилось |
| Fog | Сохранённая разведка и маска над картой | Не было отдельной семантики текущей видимости и разведанной территории |
| Бой | Сериализуемый автомат ходов, DOM-сетка 8×5, карточки/портреты и CSS-анимации | Боевые фигуры не были частью единой пространственной сцены |
| Сохранения | Основной слот, резервная копия, envelope/checksum, миграции | Валидатор не разрешал `battle.source.kind === dungeon` |
| SW/cache | Scope-specific кэш, network-first index | Обработчик navigation мог подменять посторонние страницы индексом игры; требовался новый cache/version |
| AI | Один подвижный полевой противник: перемещение, захват экономики, осада | Источниками угрозы ошибочно считались также неподвижные нейтральные армии |
| Пещера | Отдельный каталог, ресурсы, артефакты и настоящие бои | Команда сразу проходила весь маршрут; центральный охраняемый мост был изолирован |
| Музыка | Наборы простых синтезированных нот | Недостаточно самостоятельных партий, переходов и управления жизненным циклом |
| CSS | Несколько исторических слоёв override | Изменения одного экрана непредсказуемо зависели от старых правил |

Ранние T01–T37 сохранены и проходят. Полный протокол всех T01–T123 находится в `qa/regression-results.json`. Название T01 исторически говорит о 49 объектах; фактически тест обходит весь текущий каталог — 50 объектов, включая Пещеру Бездны, для обоих героев.

## Дополнительные дефекты, найденные при реализации и проверке

Исправлены: потеря центра камеры при смене размера окна; отбрасывание декора из-за смешения клеточных и проекционных координат; попадание соседних фигур в кадры атласа; отсутствие динамического hit target полевой армии; отсутствие финального снимка боя для анимации смерти; слишком маленькое поле боя в portrait; зоны без реакции между центрами боевых клеток; ложный tap боя после drag/cancel; незавершённые audio crossfade timers; бесконечный RAF в меню при незавершённом camera target; перекрытие меню индикатором угрозы; отсутствие VFX лечения и защитного заклинания.

Эти проблемы обнаружены в промежуточных сборках нового слоя, а не приписываются исходной 9.1.2. Их закрытие проверяют новые тесты и визуальный прогон.
