# 8.7.2 — видимость боевых стеков

Исправлена проблема ручного QA на iPhone: реальные бойцы в тактическом бою выглядели блекло.

Причина: глобальное CSS-правило `button:disabled { opacity: .48 }` применялось к клеткам тактической сетки. Большинство занятых или недоступных клеток являются disabled-кнопками, поэтому вместе с клеткой становился полупрозрачным и вложенный спрайт реального боевого стека.

Исправление:
- `.bgrid .cell:disabled { opacity: 1; cursor: default }` — disabled-состояние клетки больше не уменьшает прозрачность бойца;
- к реальным `.stack` добавлено только лёгкое усиление `saturate(1.08) contrast(1.06)` без изменения игровой логики;
- декоративные бойцы подложки по-прежнему отсутствуют, предводители на фоне сохранены;
- сохранения и схема состояния не менялись.

Регрессия T103 проверяет наличие и приоритет CSS-override. Полный прогон: 103 PASS / 0 FAIL.
