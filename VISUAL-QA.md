# Визуальная проверка

Среда: встроенный браузер Codex, портретные viewport 375×812, 390×844, 430×932 CSS px. Это не Safari на физическом iPhone. Данные сцен подготовлены в `scenarios.js`, сохранение только в памяти, музыка в самих fixtures выключена.

Проверены 11 сцен для каждой ширины:

| № | Сцена | Имя файла |
|---|---|---|
| 01 | Основная карта с начальной разведкой | `01-map-W.png` |
| 02 | Герой у Стального Холма, исследованная область | `02-castle-W.png` |
| 03 | Герой на промежуточной точке маршрута | `03-movement-W.png` |
| 04 | Выделенный замок | `04-selected-W.png` |
| 05 | Живой источник угрозы, 92%, осада | `05-threat-W.png` |
| 06 | Вход в Пещеру Бездны | `06-dungeon-W.png` |
| 07 | Исследованная часть пещеры | `07-dungeon-fog-W.png` |
| 08 | Поверхностный бой | `08-battle-surface-W.png` |
| 09 | Подземный бой | `09-battle-abyss-W.png` |
| 10 | Город | `10-city-W.png` |
| 11 | Герой и армия | `11-hero-W.png` |

`W` — 375, 390 или 430. Контактные листы: [375](contact-375.jpg), [390](contact-390.jpg), [430](contact-430.jpg). Отдельные PNG находятся в `screenshots`.

Во всех итоговых 33 сценах нет горизонтального overflow документа и отсутствующих видимых изображений. Контактные листы просмотрены; случайный стартовый кадр первой карты 390 px переснят после paint. Исходная 9.1.2 для сравнения: [baseline-390.png](baseline-390.png).

Сопоставление с референсами: замок, объекты, герои и армии теперь отдельные спрайты в изометрической сцене. Декор перекрывает фигуры, fog имеет мягкую границу, нет постоянных больших подписей и DOM-карточек войск на карте/поле боя. Сохраняются общая тёмная fantasy-палитра и золотые акценты. Это заметно новый renderer. Детализация ландшафта, пластика персонажей и разнообразие архитектуры проще референсов — пиксельное или художественное совпадение не заявляется.

Бой на телефоне использует более высокую проекцию, чтобы фигуры были различимы в portrait. Город остаётся меню с исходной иллюстрацией: изображение города не используется как интерактивная мировая карта.

Дополнительно: `12-zoom-and-drag-390.png`; при zoom ширина страницы остаётся 390 px, drag не расходует движение (12/12). Нажатие по Canvas боя выполняет ход и временно отключает повторные команды. Переключатель музыки включается/выключается после пользовательского жеста без зарегистрированных ошибок браузера. Прослушивание не выполнено.

`visual-results.json` — размеры, готовность и отсутствующие изображения; `interaction-results.json` — отдельный интерактивный прогон и локальный замер draw().
